# Little Learners 🧸

A playful English learning platform for young children — letters, words, numbers, animals, colors, and more through fun visual lessons, activities, and short videos.

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Start development server |
| `npm run build`| Production build         |
| `npm run preview` | Preview production build |
| `npm run lint` | Run oxlint               |

## Brand

Cute, friendly, educational, and encouraging — soft pastels with sky blue, yellow, green, pink, and purple accents.
