# Little Learners 🧸

A playful English learning platform for young children — letters, words, numbers, animals, colors, and more through fun visual lessons, activities, and short videos.

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Scripts

| Command           | Description                 |
| ----------------- | --------------------------- |
| `npm run dev`     | Start development server    |
| `npm run build`   | Production build            |
| `npm run preview` | Preview production build    |
| `npm run lint`    | Run oxlint                  |

## GitHub Pages

The site deploys automatically to GitHub Pages on every push to `main` via GitHub Actions.

Live URL (after Pages is enabled):

https://prabodhamanoranasinghe-ai.github.io/Little-Learners/

To publish manually from this branch, merge to `main` or run the **Deploy to GitHub Pages** workflow.
